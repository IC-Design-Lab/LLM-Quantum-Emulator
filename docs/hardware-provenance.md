# Provenance of the hardware modules

This repository contains SystemVerilog from two sources: output of the lab's Chisel
generator, and files produced by this project. Recording which is which matters for
citation and for redistribution, and those are separate questions.

All 92 tracked `.sv` files are classified below. The classification is from file
contents, not from directory names: a file counts as generator output if it carries the
`// Generated by CIRCT firtool-1.62.0` header, and as this project's work if a script in
this repository reproduces it or the model emitted it during the study.

## Origin not established

`generation-study/experiment/ground_truth/Circuit0_06.sv` (78 lines, one module, no gate
logic). It has no firtool header, no script in this repository reproduces it, and its
instance names (`h_q0`, `cnot_c1_t0`) are not the generator's (`m`, `m_1`, …). It does
not match the top module of either firtool copy of the same circuit. Until its origin is
established it is excluded from the MIT grant along with the rest of its directory.

## How the generator output was produced

The excluded files that carry the header were produced by lowering Chisel through CIRCT:

```
// Generated by CIRCT firtool-1.62.0
```

The Chisel source is not in this repository, and
`rag-cag-system/corpus/code_examples/*/wrapper.md` records the same fact in its front
matter (`verified: chisel_ground_truth`).

This distinction is worth stating plainly: the absence of a copyright notice in a
compiler's output says nothing about rights in the compiler's input. A build step does
not change who owns a design.

## Status

**Open source, and therefore redistributable here.** The Chisel generator these modules
come from, and the output it produces, are open source; Dr. Xiaokun Yang confirmed this
on 2026-11-17. That is the basis on which they are included — not a private permission
granted to this project.

The FPGA quantum-circuit emulator these modules implement is the group's own prior work,
published as [2] below — which shares an author with this project. Anyone reusing the
hardware should cite that paper rather than this repository; this repository's
contribution is the generation and verification work built on top of it.

The `LICENSE` at the repository root covers the code, documentation and experimental
records written for this project. It does not extend to the files listed above, which
carry the terms of the generator and its source rather than this repository's.
